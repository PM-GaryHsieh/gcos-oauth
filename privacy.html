GCOS 隱私權政策

最後更新：2026-11-17

  • GCOS 是個人自用工具，只在使用者本人的電腦上執行。
  • 經使用者授權後，GCOS 透過 Google 日曆 API 讀取行事曆清單與活動，並依使用者指示新增、修改活動。
  • 取得的資料與授權權杖只存在使用者本機，不會傳送、出售或分享給任何第三方，也不用於廣告。
  • 使用者可隨時在 Google 帳戶的「第三方存取權」頁面撤銷授權；撤銷後 GCOS 即無法再存取任何資料。
  • GCOS 對 Google API 資料的使用遵守 Google API Services User Data Policy，包括 Limited Use 規定。

Privacy Policy

  • GCOS is a personal tool that runs only on its owner's own computer.
  • With the user's consent, GCOS uses the Google Calendar API to read calendars and events and to create or update events at the user's request.
  • Data and access tokens are stored only on the user's local machine and are never sold, transferred, or shared with third parties, nor used for advertising.
  • Access can be revoked at any time from the Google Account "Third-party access" page.
  • GCOS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: open an issue at github.com/PM-GaryHsieh/gcos-oauth
